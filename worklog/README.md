# 工作日志（worklog）

按时间倒序记录每个阶段的工作复盘，用于后期复习总结。每篇日志固定回答五个问题：

1. **做了什么** --任务背景与产出物
2. **用了什么技术** --关键依赖、API、机制
3. **解决了什么问题** --问题根源分析（不只是现象）
4. **效果怎么样** --可量化的结果、验证方式
5. **遇到的问题与该怎么办** --踩坑记录 + 通用应对方法（下次再遇到怎么办）

## 新增日志的约定

- 文件名：`YYYY-MM-DD-主题.md`，一天多篇时主题区分；
- 只记工程事实和决策理由，不记流水账；
- 数量化的结果（耗时、成功率、覆盖率）必须写实测值，估算值要标注"估算"；
- 踩坑条目要写"该怎么办"--即下次遇到同类问题的通用判断方法，而不是只描述这一次的现象。
