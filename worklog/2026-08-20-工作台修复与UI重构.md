## 用了什么技术

- **react-pdf v10 内部机制**（闪烁根因的关键）：`<Page>` 组件把 `onRenderTextLayerSuccess` 放进了 text layer 的重建依赖数组；
- React 性能三板斧：`useCallback` 稳定回调、`useMemo` 稳定派生数据、函数式 setState 去重（`setWidth(prev => prev === next ? prev : next)`）；
- `ResizeObserver` 监听容器宽度（宽度取整后再比对，避免亚像素抖动）；
- `classList.toggle(cls, bool)` 替代 `remove/add` 对（天然幂等）；
- CSS 设计系统：CSS 变量 + 单色主按钮（近黑/近白）+ 单一绿色 accent（`#0e8a5f`）+ mono 字体徽标 + `tabular-nums` 数字对齐 + 发丝边框（hairline border）。

## 解决了什么问题（根因分析）

**① 高亮闪烁（最有价值的一个）**

- 现象：打开溯源预览，PDF 上的高亮矩形反复闪。
- 根因链条：传给 `<Page>` 的 `onRenderTextLayerSuccess` 是**内联箭头函数** -> 每次父组件渲染都是新引用 -> react-pdf 把它放进 text layer 重建的依赖数组 -> text layer 整体重建 -> 回调里又 `setState`（升级 textLayerVersion）-> 父组件重渲染 -> 无限循环。肉眼看到的就是"高亮不停重画"。
- 修法：删掉 `textLayerVersion` 状态，回调全部 `useCallback` 稳定化，高亮逻辑改为在 `requestAnimationFrame` 里用 `classList.toggle` 幂等上色。
- **通用判断方法**：React 里"视觉上不停闪烁/重绘"的问题，先查是否存在"回调引用不稳定 -> 子组件 effect 重跑 -> setState -> 再渲染"的死循环，而不是先怀疑 CSS 动画。

**② token 显示**：把 per-round usage 的 `useMemo` 删掉，输入区直接渲染 `sessionTotal`（会话累计），加 `toLocaleString()` 千分位。

**③ notice 残留**：`notice` 是组件 state，弹窗关闭时组件**不卸载**（Radix Dialog 只隐藏），所以值留到了下次打开。修法：`useEffect(() => { if (props.open) setNotice(""); }, [props.open])`，每次打开时清空。

**④ UI 重构**：不改任何组件结构和类名，只重写 `styles.css`，把设计收敛到一组 CSS 变量。这样重构零功能风险，后续换主题只改变量。

## 效果怎么样
